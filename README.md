# ⏳ LAST 72 HOURS
### Bunker Survival Strategy Game

A Java-based desktop survival game developed using
Java Swing in Visual Studio Code.

## 🎮 About the Game

You are trapped inside a bunker and must survive
for 72 in-game hours until a rescue team arrives.

Manage your resources, protect your health, and
make strategic decisions to survive.

## ✨ Features

- ❤️ Health management
- 🍞 Food and water resources
- ⚡ Energy and battery management
- 🩺 Medical supplies
- 🔍 Scavenging and random events
- 📻 Radio communication
- 🏆 Victory and defeat conditions

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- Visual Studio Code

## ▶️ How to Run

1. Install a compatible Java Development Kit.
2. Download `Last72Hours.java` from this repository.
3. Open a terminal in the folder containing the file.
4. Compile the program:

   javac Last72Hours.java

5. Run the game:

   java Last72Hours

## 🎯 Objective

Survive for 72 in-game hours until rescue arrives.

Manage your supplies carefully because every action
advances time and survival conditions can change.
